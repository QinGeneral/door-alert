# 门后有人提示器：双板配套固件

## 当前硬件与接线

| 角色 | MAC | 当前USB串口 | 接线 |
| --- | --- | --- | --- |
| 门前 | AC:27:6E:7F:D3:20 | /dev/cu.usbmodem101 | AM312 OUT=D2/GPIO4；VCC=3V3；共地。灯R=D6/GPIO21，Y=D7/GPIO20，G=D10/GPIO10，共阴端=GND |
| 门后 | AC:27:6E:7F:C3:B4 | /dev/cu.usbmodem2101 | VL53L5CX VIN=3V3，GND=GND，SDA=D4/GPIO6，SCL=D5/GPIO7，INT及LPn留空 |

角色绑定实测MAC，烧录到错误板子时不会启用无线配对。重插后串口名称可能变化。
两板均为XIAO ESP32-C3，4MB Flash。门后USB供电；门前当前也是USB调试。

## 工作方式

- 固定信道6，通过加密ESP-NOW单播直连，不连接路由器或互联网。
- 门后8×8、10Hz连续测距，每200ms发送一次状态，门前每秒发送HELLO。
- 门前只信任指定门后MAC。每包校验协议版本、长度和序列；断线、传感器错误、
  数据超过1秒、有效测距覆盖不足、校准期间均显示闪黄灯。未知状态不会亮绿。
- 红灯：门后检测到前景物体；绿灯：当前检测规则未检测到前景；黄灯：未知/异常。
- USB接电脑时持续显示，方便联调。USB接充电头或电池供电时，初次给AM312预留30秒，
  AM312触发后保持显示15秒；无人活动后关灯、关闭无线并进入GPIO唤醒的轻睡眠。
  每30秒定时检查是否新接入电脑。未在电池供电下实测睡眠电流、唤醒和续航。
- 门后先在无线关闭时完成测距并等到第一帧，再打开 ESP-NOW；无线起来后重新挂上 I²C。
  探测失败、连续读失败或 5 秒没有新帧时关掉无线，重新初始化传感器。
  调试日志非阻塞，不依赖电脑一直打开串口。
- 只检测几何前景物体，不区分儿童、成人或物品；绿色只代表本算法没有检测到目标。

## 目前默认：桌面模式 DESK

因为硬件还未安装在门框，默认使用可重复测试的桌面规则：测距状态有效且距离在
1–39mm 的区域直接视为有人；40–1000mm 内的物体需要两个上下或左右相邻区域，
连续两帧后判定有物体。撤去后保持红灯至少2秒，连续三帧满足空场才变绿。
对角像素不算相邻。至少48/64个区域有有效测距才允许判定空场。距离为 0 或状态无效的区域不计入。
无有效反射/对着远处空旷区域/覆盖不足时显示黄灯，不能当作无人。

桌面测试：探头对着1.5–2米处墙面保持不动，再放入和移开20–50cm处的手掌或物体。
桌面阈值不适合装在2米高门框后直接使用。

## 装到门框后的空场校准

1. 固定门后探头角度，使视野覆盖门扇扫过的区域，保持安装位置不动。
2. 清空门后区域，门的位置保持与实际检测时一致。
3. 门后板正常运行时，长按BOOT约2秒后松开，或在门后串口发送`CAL\n`。
4. 收到命令后有10秒离开区域的时间；之后采集32帧，约3.2秒。期间黄灯。
5. 至少48个区域有24次以上有效样本、距离波动不超过120mm时保存基线。
   失败会输出原因，不会拿不完整数据生成绿色。
6. 校准成功后使用“比背景近至少300mm的两个相邻区域”检测前景，基线存入NVS，重启保留。

不要在上电/重启时按住BOOT，以免进入下载模式。不要在有人位于危险区域时校准。
移动探头、更改角度、门位置或背景后必须重新校准。校准仅建立几何基线，不代替实地测试。

## 串口指令（115200）

| 板子 | 指令 | 作用 |
| --- | --- | --- |
| 门后 | STATUS | 输出当前状态 |
| 门后 | GRID | 下一帧输出64个距离；0代表无有效测距 |
| 门后 | SCAN | 输出I²C总线电平及应答地址，不伪造测距结果 |
| 门后 | CAL | 倒计时10秒后采集空场背景 |
| 门后 | DESK | 删除已存基线，恢复1米桌面模式 |
| 门前 | STATUS | 输出状态 |
| 门前 | WAKE | 手动保持显示15秒，不伪造传感器或门后状态 |

门前的PIR只控制显示/待机，不直接控制红绿灯。红绿状态来自门后的实际测距。
不要将接近门前触发AM312误认为门后检测到了人。

## 构建与文件

`platformio.ini`固定平台8.0.0；分别使用`rear`和`front`构建环境。
本机工具缓存路径记录于`BUILD.md`。源代码位于`include/`和`src/`。
`include/pairing_keys.h`为本地生成的一对配套密钥，已加入.gitignore，勿公开，
两板重新编译时需使用同一份；更换密钥后须重烧两板。

测距驱动为SparkFun VL53L5CX Arduino Library 1.0.3，固定官方提交
`248607060e49d18bdf064c6aa411ffe515993d16`，源码及许可证保留于
`lib/SparkFun_VL53L5CX/`，未修改驱动源码。

`tests/detection_test.cpp`验证邻接、判定延迟、保持时间、异常状态及计时溢出。
`tools/record_live.py`记录真实双板串口并核对绿色必须来自新鲜CLEAR状态。
`verification/`保存当前实机结果，`release/`保存配套烧录文件与SHA256。

正式安装后仍需测试：小孩站/蹲/坐、贴门、强光和衣物、遮挡、开关门、断电断线，
以及门前电池供电的唤醒。设备只用于辅助提醒，开门时仍需慢开。
