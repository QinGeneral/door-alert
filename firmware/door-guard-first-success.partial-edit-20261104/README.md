# 首次成功版本回退对照

本目录按本次会话中第一次成功测距的双板源代码重建；不是当时原始二进制的逐字节恢复。
`ROLLBACK.json`列出了重建依据及撤回内容。当前较新版本保留在相邻的`door-guard`目录。

- 门前：AC:27:6E:7F:D3:20；R=D6、Y=D7、G=D10、AM312 OUT=D2。
- 门后：AC:27:6E:7F:C3:B4；模块VIN=3V3、GND=GND、SDA=D4、SCL=D5。
- 保留同一份ESP-NOW密钥、驱动、信道、阈值、10Hz测距与NVS校准数据。
- 移除后来新增的I²C总线扫描、非阻塞日志配置和更严格的新鲜度判断。
- 回退版的USB日志可能在无人读取时拖慢程序，这是历史版本行为，仅用于对照排查。
- 默认桌面模式，约1米内两个相邻区域近物体触发红灯；异常、过期数据为黄灯。
- 现场安装前仍需校准并验证覆盖范围。源码回退不代表模块故障已经排除。

构建使用`platformio.ini`的rear/front环境。回烧及实机记录保存于`verification/rollback/`。
配对密钥位于忽略文件`include/pairing_keys.h`，两板需保持一致，勿公开。
